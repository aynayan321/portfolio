CodeSync — Real-Time Collaborative Code Editor

JavaScriptNode.jsExpress.jsSocket.IOWebSockets
Full-stackReal-time

A browser-based code editor where multiple users write and edit code together, live — a lightweight collaborative IDE built on WebSockets, with room-based sessions and instant sync across every connected client.

What I built
  • Architected a Node.js + Express backend with Socket.IO to broadcast code changes to all clients the instant they happen.
  • Designed room-based sessions so different teams can collaborate in isolated, conflict-free workspaces.
  • Implemented event-driven live updates to keep every editor in sync while staying responsive.
  • Handled late joiners & reconnections, restoring the latest document state so no edits are lost.
  • Documented the technical design and setup steps for reproducibility and future handoff.
The challenge

Keeping every client's editor perfectly synchronized under concurrent edits — and resolving conflicts without losing updates.

Outcome

A smooth, low-latency multi-user editing experience; synchronization bugs found during multi-client testing were identified and fixed.

Full-stackAuth + Realtime

What I built

A working multi-user cart with secure, synced sessions; data-consistency issues uncovered in testing were resolved.
